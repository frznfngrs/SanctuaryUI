# SanctuaryUI

A Diablo III style combat HUD for WoW Forever.

## Install

In [WowUp](https://wowup.io), choose **Install from URL** and enter:

```
https://github.com/frznfngrs/SanctuaryUI
```

## Suggest a feature

- **In game:** type `/sanctuary request`, or open the options and go to **Feedback**. Write your idea, copy the link it gives you, and paste it into a browser.
- **On GitHub:** [open a feature request](https://github.com/frznfngrs/SanctuaryUI/issues/new?template=feature_request.yml).

Either way it arrives here tagged `enhancement`. You can see what's already been asked for in the [list of requests](https://github.com/frznfngrs/SanctuaryUI/issues?q=is%3Aissue+label%3Aenhancement).

## Report a bug

If SanctuaryUI hits an error, it offers to make a report for you. You can also type `/sanctuary report` at any time. Copy the link it gives you and paste it into a browser. Nothing is sent until you submit it on GitHub.
